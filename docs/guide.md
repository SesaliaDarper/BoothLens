# 使用指南

[← 返回项目首页](../README.md)

## 目录应如何组织

```text
AssetLibrary/
├─ Avatars/                     分类
│  └─ ExampleAvatar/            一个完整资源
│     ├─ Avatar.unitypackage
│     ├─ ColorPack.zip
│     └─ Textures/              不生成单独卡片
├─ Clothing/
│  └─ ExampleOutfit/
└─ Tools/
```

分类名称不限于特定语言或编号。只扫描素材专用目录，避免选择整个磁盘或完整 Unity 工程。

- **自动识别**：结合浅层结构判断分类与资源。
- **整个资源库**：从根目录向下识别分类。
- **单个分类**：把当前目录的子项作为资源入口。
- **单个资源**：当前目录整个合为一个资源。

有歧义时，展开“高级：目录结构与修复”，把目录固定为分类或完整资源。固定边界优先于自动判断；“自动判断”可清除规则。不联网修复仅重建索引，保留素材、人工关联、候选与缓存。

## 识别与候选

1. 校验资源文件夹与同组归档名称中的 BOOTH 编号。
2. 编号准确命中可直接绑定；404 后才继续名称搜索，网络错误单独显示。
3. 名称搜索使用资源文件夹名，候选只显示文字，不预下载候选图片。
4. 人工确认后获取一个商品封面。不抓取商品图集与店铺头像。

已绑定和已有候选的资源会优先跳过内部遍历和联网。新增资源仍可从根/分类浅层发现。

## 纠正错误绑定

资源详情提供 **更换绑定** 和 **清除绑定**。

清除绑定会保留素材、包成员、本地图、商品缓存和导入记录。资源回到未匹配；普通重扫不会恢复旧编号。可以直接指定正确商品，或在“路径与识别信息”中点击“清除候选，下次扫描重查”，再主动扫描。

扫描进行时需等待结束后再清除绑定，以免后台结果覆盖操作。

## 配图

**对应 BOOTH 商品封面 > 本地配图**。

没有绑定商品时使用本地图，可以在详情中自行上传 JPG、PNG、WebP、GIF（最大 8 MiB）。上传图复制至应用数据目录，不改原始素材；重扫保留手动选图。清除本地图后可重新上传，或标记刷新后扫描以重新自动选图。

## Unity 桥接

1. 从设置页下载脚本或 ZIP。
2. 放到目标工程 `Assets/Editor/BoothRelay.cs`；ZIP 内已经包含该路径。
3. 等待 Unity 编译完成。
4. 在资源详情选择包，打开导入窗口并刷新工程列表。
5. 多个 Editor 同时打开时核对工程名称和完整路径，再提交。

桥接每两秒写心跳，程序检查进程、启动时间与有效期。关闭的工程、过期记录和忙碌 Editor 不作为可提交目标，不回退到历史路径，也不自动启动关闭的工程。

`.unitypackage` 使用 Unity 原生导入，保留 GUID 与包内路径；普通 ZIP 先在独立 staging 目录检查和解包。不会自动安装 VRCSDK、lilToon 等依赖。导入成功以 Unity 回传结果为准。

## 启动、升级与备份

- 服务只监听 `127.0.0.1`；网页关闭不代表服务停止，关闭启动窗口才停止。
- 默认数据在 `%LOCALAPPDATA%\BoothLens`，不要把它混进源代码仓库。
- 升级只替换应用程序，保留数据目录。
- 备份前退出程序，再复制整个数据目录。
- Cookie 仅保存在当前进程内存，退出后需重新填写。公共商品通常不需要 Cookie。
- 服务重启后刷新网页，避免使用旧会话令牌。

## 常见问题

### 分类不见了

先点击“清除筛选”。若确实是分类被识别成完整资源，在高级设置指定分类边界，再执行不联网目录修复。扫描子分类不会隐藏其兄弟分类。

### 下载桥接脚本失败

新版脚本内嵌程序，不依赖外置文件。刷新后重试，或使用 ZIP 备用下载。脚本也保存在仓库的 [unity 目录](../unity/BoothRelay.cs)。

### 没有发现 Unity 工程

确认 Editor 仍在运行、脚本已放入 `Assets/Editor` 且无编译错误，再刷新工程列表。Unity 忙碌时稍候再试。

### 素材找不到对应商品

可以手动建档用于第三方或下架素材，再按其自定义 ID 关联资源；也可以暂不关联并使用本地图。
