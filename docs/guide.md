# 使用指南

[← 返回项目首页](../README.md)

## 启动与退出

解压完整发布包后双击 `Start-BoothLens.exe`。程序自动开启本地服务，在 **WebView2 原生桌面窗口**中显示资源库，无需 CMD 窗口或额外安装 .NET。

- Windows 需要 **Microsoft Edge WebView2 Runtime**，当前 Windows 10 / 11 通常已内置。若窗口提示缺失，请安装 [WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/#download)，然后重新打开主界面。
- 菜单“在浏览器打开”可备用访问 `http://127.0.0.1:5180`；它与桌面窗口使用同一个本地服务。WebView2 待安装时也可先使用浏览器。
- 关闭桌面窗口只会收起到系统托盘，不退出程序；服务保持运行，桥接脚本和 ZIP 下载、扫描与导入继续可用。双击托盘图标恢复窗口。
- 托盘菜单“退出 BoothLens”会请求其自行启动的服务正常退出；若服务原本由其他方式启动，则保留该服务。仅关闭备用浏览器也不会停止服务。
- 重复双击会激活现有桌面窗口，避免启动第二个实例。
- 菜单“服务与日志”提供状态、日志和重新启动按钮。启动失败时请检查这里，并保留完整发布目录；单独复制桌面 EXE 不会包含后端。

## 目录应如何组织

```text
AssetLibrary/
├─ Avatars/                     分类
│  └─ ExampleAvatar/            一个完整资源
│     ├─ Avatar.unitypackage
│     ├─ ColorPack.zip
│     └─ Textures/              不生成单独卡片
├─ Clothing/
│  └─ ExampleOutfit/
└─ Tools/
```

分类名称不限于特定语言或编号。只扫描素材专用目录，避免选择整个磁盘或完整 Unity 工程。

- **自动识别**：结合浅层结构判断分类与资源。
- **整个资源库**：从根目录向下识别分类。
- **单个分类**：把当前目录的子项作为资源入口。
- **单个资源**：当前目录整个合为一个资源。

有歧义时，展开“高级：目录结构与修复”，把目录固定为分类或完整资源。固定边界优先于自动判断；“自动判断”可清除规则。不联网修复仅重建索引，保留素材、人工关联、候选与缓存。

## 外观与夜间模式

顶栏提供浅色/深色快捷切换。设置 → 外观可选择浅色、深色或跟随系统。选择存于当前浏览器；跟随系统会实时响应系统外观变化，跨标签页也同步选择。默认跟随系统。

## 移除与恢复分类

资源库或扫描整理页面的分类行右侧提供“管理分类”。移除分类只影响索引显示：该分类及其子分类下的资源归入“未分类”，磁盘文件夹、文件、商品绑定、配图、候选和导入记录保持原样。

规则按素材根目录独立保存，普通扫描和目录修复不会自动恢复。管理分类中可随时恢复，无需扫描或联网。若父分类已移除，先恢复父分类；同名但属于另一素材根目录的分类不受影响。这里不执行物理删除文件夹。

## 识别与候选

1. 校验资源文件夹与同组归档名称中的 BOOTH 编号。
2. 编号准确命中可直接绑定；404 后才继续名称搜索，网络错误单独显示。
3. 名称搜索使用资源文件夹名，候选只显示文字，不预下载候选图片。
4. 人工确认后获取一个商品封面。不抓取商品图集与店铺头像。

已绑定和已有候选的资源会优先跳过内部遍历和联网。新增资源仍可从根/分类浅层发现。

## 纠正错误绑定

资源详情提供 **更换绑定** 和 **清除绑定**。

清除绑定会保留素材、包成员、本地图、商品缓存和导入记录。资源回到未匹配；普通重扫不会恢复旧编号。可以直接指定正确商品，或在“路径与识别信息”中点击“清除候选，下次扫描重查”，再主动扫描。

扫描进行时需等待结束后再清除绑定，以免后台结果覆盖操作。

## 配图

**对应 BOOTH 商品封面 > 本地配图**。

没有绑定商品时使用本地图，可以在详情中自行上传 JPG、PNG、WebP、GIF（最大 8 MiB）。上传图复制至应用数据目录，不改原始素材；重扫保留手动选图。清除本地图后可重新上传，或标记刷新后扫描以重新自动选图。

## Unity 桥接

1. 从设置页下载脚本或 ZIP。
2. 放到目标工程 `Assets/Editor/BoothRelay.cs`；ZIP 内已经包含该路径。
3. 等待 Unity 编译完成。
4. 在资源详情选择包，打开导入窗口并刷新工程列表。
5. 多个 Editor 同时打开时核对工程名称和完整路径，再提交。

桥接每两秒写心跳，程序检查进程、启动时间与有效期。关闭的工程、过期记录和忙碌 Editor 不作为可提交目标，不回退到历史路径，也不自动启动关闭的工程。

`.unitypackage` 使用 Unity 原生导入，保留 GUID 与包内路径；普通 ZIP 先在独立 staging 目录检查和解包。不会自动安装 VRCSDK、lilToon 等依赖。导入成功以 Unity 回传结果为准。

## 启动、升级与备份

- 服务只监听 `127.0.0.1`；关闭桌面窗口会收起到托盘，关闭备用浏览器也不停止服务。需要完全退出时，在托盘菜单选择“退出 BoothLens”。
- 默认数据在 `%LOCALAPPDATA%\BoothLens`，不要把它混进源代码仓库。
- 升级只替换应用程序，保留数据目录。
- 备份前退出程序，再复制整个数据目录。
- Cookie 仅保存在当前进程内存，退出后需重新填写。公共商品通常不需要 Cookie。
- 服务重启后刷新网页，避免使用旧会话令牌。

## 常见问题

### 分类不见了

先点击“清除筛选”。若确实是分类被识别成完整资源，在高级设置指定分类边界，再执行不联网目录修复。扫描子分类不会隐藏其兄弟分类。

### 下载桥接脚本失败

先确认 BoothLens 仍在运行，可检查系统托盘或“服务与日志”。关闭桌面窗口只是收起到托盘，下载仍可继续；选择退出后，备用浏览器里保留的页面并不代表服务在线。服务退出后下载会出现连接错误，页面会提示“本地服务连接中断”。重新双击 `Start-BoothLens.exe`，再重新加载主界面或刷新备用浏览器重试。

脚本内嵌程序，不依赖外置文件。设置页提供脚本、ZIP 和独立的 GitHub 备用下载；下载失败会显示具体提示。完整发布包根目录的 `unity/BoothRelay.cs` 也能直接复制，无需启动服务或联网。脚本同样保存在仓库的 [unity 目录](../unity/BoothRelay.cs)。

### 没有发现 Unity 工程

确认 Editor 仍在运行、脚本已放入 `Assets/Editor` 且无编译错误，再刷新工程列表。Unity 忙碌时稍候再试。

### 素材找不到对应商品

可以手动建档用于第三方或下架素材，再按其自定义 ID 关联资源；也可以暂不关联并使用本地图。
